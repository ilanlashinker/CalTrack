# 🥗 CalTrack

> Simple, offline-first calorie tracking with weight trends and activity logging.

אפליקציית ווב מלאה למעקב קלוריות, משקל ופעילות גופנית פועלת כולה בדפדפן, ללא שרת וללא התחברות.

## ✨ פיצ'רים עיקריים

### 🗓️ תפריט שבועי
- מעקב קלוריות יומי מחולק ל-4 ארוחות (בוקר, צהריים, ערב, נשנוש)
- סרגל התקדמות חזותי עם ציון צבעוני (ירוק / צהוב / אדום) לפי יעד קלורי
- השלמה אוטומטית (autocomplete) של מאכלים מהיסטוריה קודמת
- לחצני ניווט בין ימי השבוע

### 📅 לוח שנה אינטראקטיבי
- תצוגה חודשית עם נקודות צבע לפי ביצוע יומי
- לחיצה על יום עבר מציגה סיכום ארוחות בחלון מוקפץ

### ⚖️ מעקב משקל
- רישום משקל יומי עם גרף SVG מובנה
- חישוב ירידה כוללת וירידה שבועית
- גרף משולב משקל × ממוצע קלורי שבועי (תצוגת מגמה)

### 🏃 מעקב פעילות גופנית
- תמיכה ב-6 סוגי פעילות: הליכה, ריצה, אימון, שחייה, רכיבה, אחר
- חישוב הערכת שריפת קלוריות לפי נוסחת MET + **משקל שהיה פעיל באותו תאריך** (לא המשקל הנוכחי)
- מד רצף (streak) ימים פעילים רצופים

### 📉 גרעון קלורי
- חישוב TDEE (הוצאה קלורית יומית) לפי נוסחת **Mifflin-St Jeor**
- חישוב TDEE דינמי מבוסס היסטוריה (EMA על שינויי משקל × קלוריות בפועל)
- **TDEE בסיסי אחיד לכל הימים** - אותו TDEE אפקטיבי (סטטי/דינמי) משמש בסיס לכל הימים, כך שתיעוד משקל חדש לא משנה רטרואקטיבית את הגרעון של ימים קודמים
- **שריפת פעילות לפי משקל היסטורי** - שריפת הקלוריות מהפעילות (MET) בכל יום מחושבת לפי המשקל שהיה פעיל באותו תאריך, ומתווספת ל-TDEE הבסיסי
- **גרעון מצטבר וק"ג שומן תיאורטי** - סיכום מתחילת הדיאטה (ימים ללא נתונים לא נכללים)
- **מיון רשימת הימים** - לפי תאריך (חדש/ישן) או לפי גרעון (גבוה/נמוך)
- **פרטי חישוב לכל יום** - בכל כרטיסיית יום מוצגים המשקל ההיסטורי וה-TDEE הבסיסי ששימשו לחישוב אותו יום

### 🔥 מאזן יומי
- חישוב קלוריות נטו: אכולות פחות שרופות
- חישוב שריפת פעילות לפי **משקל שהיה פעיל באותו תאריך**
- תצוגה לפי ימי פעילות

### ⚙️ הגדרות
- שם משתמש, יעד קלורי יומי, משקל התחלתי
- נתוני TDEE: גיל, גובה, מין, רמת פעילות

### 💾 גיבוי ושחזור
- ייצוא כל הנתונים לקובץ **JSON**
- שחזור מקובץ גיבוי
- ייצוא לוג מפורט ל-**Excel** (3 גיליונות: פירוט, סיכום יומי, גרעון)

## ✨ הערכת קלוריות ומאקרו ע"י AI (אופציונלי)

לחצן ה-✨AI ליד הוספת מאכל שולח את שם המאכל לפונקציית שרת קטנה (Cloudflare Worker) שמחזירה הערכת קלוריות + חלבון/פחמימות/שומן מ-Gemini. זו התוספת היחידה באפליקציה שדורשת רשת ושרת — הכל שאר האפליקציה ממשיכה לעבוד אופליין בלי זה, וגם הוספת מאכלים ידנית תמיד עובדת.

### הקמה חד-פעמית

1. **מפתח Gemini (חינם, בלי כרטיס אשראי)**: כנסו ל-https://aistudio.google.com/apikey, התחברו עם חשבון Google, ולחצו "Create API key".
2. **חשבון Cloudflare (חינם)**: הירשמו ב-https://dash.cloudflare.com/sign-up אם אין לכם עדיין.
3. **פריסת ה-Worker**:
   ```bash
   cd worker
   npx wrangler login
   npx wrangler kv namespace create RATE_LIMIT
   # העתיקו את ה-id שמוחזר לתוך wrangler.toml (kv_namespaces.id)
   npx wrangler secret put GEMINI_API_KEY
   # הדביקו את מפתח ה-Gemini כשמתבקשים
   npx wrangler deploy
   ```
4. פקודת ה-deploy תדפיס URL כמו `https://caltrack-estimate.<subdomain>.workers.dev` — הדביקו אותו כערך `AI_ESTIMATE_URL` ב-`menu.html` (ליד `FOOD_KEY`), ואם משנים דומיין ל-GitHub Pages שאינו `https://ilanlashinker.github.io`, עדכנו גם את `ALLOWED_ORIGIN` ב-`worker/wrangler.toml`.

השכבה כוללת timeout (כדי שהכפתור לא יישאר תקוע) והגבלת קצב בסיסית לפי IP (20 בקשות בשעה) כך שאם ה-URL של ה-Worker ידלוף, לא ניתן יהיה לנצל אותו בלי הגבלה.

## ⚠️ הגבלות ידועות

- הנתונים שמורים **רק בדפדפן הנוכחי** - לא מסונכרנים בין מכשירים
- חישוב שריפת קלוריות לפי MET הוא הערכה בלבד (שגיאה אפשרית של 30–50%)
- חישוב TDEE מדויק לפחות ±10%
