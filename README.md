# 🥗 CalTrack

> Simple, offline-first calorie tracking with weight trends and activity logging.

אפליקציית ווב מלאה למעקב קלוריות, משקל ופעילות גופנית, פועלת כולה בדפדפן, ללא שרת וללא התחברות.

## ✨ פיצ'רים עיקריים

### 🗓️ תפריט שבועי
- מעקב קלוריות יומי מחולק ל-4 ארוחות (בוקר, צהריים, ערב, נשנוש)
- סרגל התקדמות חזותי עם ציון צבעוני (ירוק / צהוב / אדום) לפי יעד קלורי
- בחירת כמות יחידות (1 עד 10) לכל פריט מזון, למשל 3x ביצה
- השלמה אוטומטית (autocomplete) של מאכלים מהיסטוריה קודמת
- לחצני ניווט בין ימי השבוע

### 🤖 הערכת קלוריות ומאקרו בעזרת AI (אופציונלי)
- כפתור ✨AI ליד הוספת מאכל, מעריך קלוריות, חלבון, פחמימות ושומן לפי שם המאכל בלבד
- ההערכה עוברת דרך צינור דו-שלבי בתוך Cloudflare Worker קטן, כדי שאף מפתח API לא ייחשף בדפדפן: קודם תרגום התיאור מעברית לאנגלית (DeepL, שירות תרגום ייעודי), ואז חישוב תזונתי מהטקסט האנגלי (Groq, מודל openai/gpt-oss-120b)
- הפיצול הזה נבחר אחרי בדיקות מקיפות: מודלי AI כלליים (Gemini, וגם Groq עצמו) התבררו כלא אמינים כשמזינים אותם ישירות עברית קצרה, אך מדויקים מאוד באנגלית. שירות תרגום ייעודי (לא LLM) פותר את זה. שירות תרגום חינמי ראשון (MyMemory) נבדק ונפסל: הגבלת הקצב שלו מבוססת כתובת IP, ו-Cloudflare Workers משתפים מאגר כתובות IP יוצאות בין המון לקוחות שונים, כך שההגבלה נחצתה ממקורות שאינם בשליטתנו. DeepL, לעומת זאת, מזוהה לפי מפתח API אישי
- כולל הגנת timeout (הכפתור לא נשאר תקוע), הגבלת קצב בסיסית לפי כתובת IP, ומנגנון retry אוטומטי אם מתקבלת תשובה ריקה (אפס קלוריות) שמעידה על כשל מוסווה
- הודעות שגיאה נפרדות וברורות למשתמש: מכסה יומית שנגמרה, כשל בתרגום, או תקלה כללית זמנית, במקום כישלון שקט
- תכונה אופציונלית לגמרי: בלעדיה כל האפליקציה, כולל הוספת מאכלים ידנית, ממשיכה לעבוד אופליין כרגיל. פרטי הקמה מלאים בהמשך המסמך
- **חשוב לדיוק ההערכה**: כתבו בשם המאכל תיאור מדויק ומפורט ככל האפשר, כולל משקל, שיטת הכנה, ותוספות (או היעדרן), ולא מילה בודדת. למשל "חזה עוף 150 גרם שטוגן בנינג'ה גריל בלי תוספת שמן" ולא סתם "עוף". תיאור מפורט משפר גם את דיוק התרגום וגם את דיוק החישוב התזונתי

### 📱 עבודה אופליין והתקנה כאפליקציה
- כל האפליקציה פועלת מקומית בדפדפן, ללא צורך בחיבור לאינטרנט (מלבד תכונת ה-AI האופציונלית)
- ניתנת להתקנה למסך הבית כאפליקציה עצמאית (PWA) דרך manifest.json ואייקונים ייעודיים
- Service Worker (`sw.js`) שומר cache מקומי של כל הקבצים לעבודה מהירה ואופליינית, עם ניהול גרסאות שמבטיח קבלת עדכונים חדשים בכל פריסה

### 📅 לוח שנה אינטראקטיבי
- תצוגה חודשית עם נקודות צבע לפי ביצוע יומי
- לחיצה על יום עבר מציגה סיכום ארוחות בחלון מוקפץ



### ⚖️ מעקב משקל
- רישום משקל יומי עם גרף SVG מובנה
- חישוב ירידה כוללת וירידה שבועית
- גרף משולב משקל × ממוצע קלורי שבועי (תצוגת מגמה)

### 🏃 מעקב פעילות גופנית
- תמיכה ב-6 סוגי פעילות: הליכה, ריצה, אימון, שחייה, רכיבה, אחר
- חישוב הערכת שריפת קלוריות לפי נוסחת MET, בשילוב **משקל שהיה פעיל באותו תאריך** (לא המשקל הנוכחי)
- מד רצף (streak) ימים פעילים רצופים

### 📉 גרעון קלורי
- חישוב TDEE (הוצאה קלורית יומית) לפי נוסחת **Mifflin-St Jeor**
- חישוב TDEE דינמי מבוסס היסטוריה (EMA על שינויי משקל × קלוריות בפועל)
- **TDEE בסיסי אחיד לכל הימים**: אותו TDEE אפקטיבי (סטטי/דינמי) משמש בסיס לכל הימים, כך שתיעוד משקל חדש לא משנה רטרואקטיבית את הגרעון של ימים קודמים
- **שריפת פעילות לפי משקל היסטורי**: שריפת הקלוריות מהפעילות (MET) בכל יום מחושבת לפי המשקל שהיה פעיל באותו תאריך, ומתווספת ל-TDEE הבסיסי
- **גרעון מצטבר וק"ג שומן תיאורטי**: סיכום מתחילת הדיאטה (ימים ללא נתונים לא נכללים)
- **מיון רשימת הימים**: לפי תאריך (חדש/ישן) או לפי גרעון (גבוה/נמוך)
- **פרטי חישוב לכל יום**: בכל כרטיסיית יום מוצגים המשקל ההיסטורי וה-TDEE הבסיסי ששימשו לחישוב אותו יום

### 🔥 מאזן יומי
- חישוב קלוריות נטו: אכולות פחות שרופות
- חישוב שריפת פעילות לפי **משקל שהיה פעיל באותו תאריך**
- תצוגה לפי ימי פעילות

### ⚙️ הגדרות
- שם משתמש, יעד קלורי יומי, משקל התחלתי
- נתוני TDEE: גיל, גובה, מין, רמת פעילות

### 💾 גיבוי ושחזור

## 🚀 הפעלה

```bash
# אין צורך בהתקנה, פתח את הקובץ ישירות בדפדפן
open menu.html
```

או פשוט גרור את `menu.html` לחלון הדפדפן. **אין תלויות חיצוניות, אין npm, אין שרת.** (תכונת הערכת ה-AI האופציונלית היא היוצאת מן הכלל היחידה, ראו בהמשך).

## ✨ הקמת תכונת הערכת ה-AI (אופציונלי)

לחצן ה-✨AI ליד הוספת מאכל שולח את התיאור לפונקציית שרת קטנה (Cloudflare Worker), שמריצה שני שלבים: תרגום לאנגלית (DeepL), ואז הערכה תזונתית מהטקסט האנגלי (Groq). זו התוספת היחידה באפליקציה שדורשת רשת ושרת: שאר האפליקציה ממשיכה לעבוד אופליין בלעדיה, וגם הוספת מאכלים ידנית תמיד עובדת.

### הקמה חד-פעמית

1. **מפתח Groq (חינם, בלי כרטיס אשראי)**: כנסו ל-https://console.groq.com, צרו חשבון, וצרו API key חדש. מכסת החינם: 1,000 בקשות ביום ל-openai/gpt-oss-120b.
2. **מפתח DeepL (חינם, בלי כרטיס אשראי)**: כנסו ל-https://www.deepl.com/en/pro-api, צרו חשבון, וצרו API key. מפתחות בתוכנית "Developer" מקבלים קרדיט חד-פעמי של כ-1,000,000 תווים, שמספיק לשנים של שימוש אישי. **חשוב**: מפתחות ברמה החינמית מסתיימים ב-`:fx` וחייבים את הכתובת `api-free.deepl.com` (לא `api.deepl.com`), כפי שכבר מוגדר בקוד.
3. **חשבון Cloudflare (חינם)**: הירשמו ב-https://dash.cloudflare.com/sign-up אם אין לכם עדיין.
4. **פריסת ה-Worker**:
   ```bash
   cd worker
   npx wrangler login
   npx wrangler kv namespace create RATE_LIMIT
   # העתיקו את ה-id שמוחזר לתוך wrangler.toml (kv_namespaces.id)
   npx wrangler secret put GROQ_API_KEY
   npx wrangler secret put DEEPL_API_KEY
   # הדביקו כל מפתח כשמתבקש
   npx wrangler deploy
   ```
5. פקודת ה-deploy תדפיס URL כמו `https://caltrack-estimate.<subdomain>.workers.dev`. הדביקו אותו כערך `AI_ESTIMATE_URL` ב-`menu.html` (ליד `FOOD_KEY`). אם משנים דומיין ל-GitHub Pages שאינו `https://ilanlashinker.github.io`, עדכנו גם את `ALLOWED_ORIGIN` ב-`worker/wrangler.toml`.

השכבה כוללת timeout (כדי שהכפתור לא יישאר תקוע) והגבלת קצב בסיסית לפי IP (20 בקשות בשעה), כך שאם ה-URL של ה-Worker ידלוף, לא ניתן יהיה לנצל אותו בלי הגבלה. מספר זה נבחר לשימוש אישי סביר, ואינו קשור למכסות של DeepL או Groq עצמם.

**חשוב לאבטחה**: אם מפתח API כלשהו נחשף בטעות (למשל הודפס בטרמינל, נשלח בצ'אט), החליפו אותו מיד בקונסולת הספק (יצירת מפתח חדש וביטול הישן), גם אם אין ודאות שהוא דלף בפועל.

### דיבוג

אם ה-AI מחזיר שגיאה, הריצו `npx wrangler tail` מתוך תיקיית `worker` תוך כדי לחיצה על הכפתור באתר, כדי לראות את השגיאה המדויקת (תרגום שנכשל, שגיאת Groq, מכסה שנגמרה וכו').

## ⚠️ הגבלות ידועות

- הנתונים שמורים **רק בדפדפן הנוכחי**, לא מסונכרנים בין מכשירים
- חישוב שריפת קלוריות לפי MET הוא הערכה בלבד (שגיאה אפשרית של 30 עד 50 אחוז)
- חישוב TDEE מדויק לפחות ±10%
- הערכת ה-AI היא הערכה כללית בלבד, ואינה תחליף למידע תזונתי מדויק מהיצרן
- כמו כל שירות תרגום אוטומטי, ייתכנו לעיתים נדירות תרגומים לא מדויקים, בעיקר לקלט קצר או כללי מדי. תיאור מפורט (ראו הטיפ למעלה) משפר את הסיכויים לתרגום נכון
